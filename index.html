                        Video trasparente per Safari / iPhone (HEVC)
                        
                        

                            Il .mov esportato è ProRes 4444 con trasparenza. Per Safari, iPhone e iPad va
                            trasformato in HEVC, una volta sola, su un Mac:

                            1. clic destro sul file .mov nel Finder

                            2. Servizi (o Azioni rapide) → Codifica file video selezionati

                            3. Impostazione HEVC 1080p (o 4K) e spunta Mantieni trasparenza

                            Nella pagina web:

                            <video autoplay loop muted playsinline>
  <source src="idle-hevc.mov" type="video/quicktime; codecs=hvc1.1.6.H120.b0">
  <source src="idle.webm" type="video/webm; codecs=vp09.00.41.08">
</video>

                            L'HEVC va prima: Safari prende quello (trasparente), Chrome / Firefox /
                            Android il WebM.
